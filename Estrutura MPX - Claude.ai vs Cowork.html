Criativos & Relatórios

🧠 O que fica no Claude.ai

  • Tudo que o Claude precisa "saber" sobre o cliente
  • Briefing, objetivos, público-alvo, tom de voz
  • Histórico resumido de resultados
  • Plano de serviço contratado
  • Informações que não mudam com frequência

💻 O que fica no Computador

  • Tudo que o Claude produz para o cliente
  • Relatórios, roteiros, copies, planilhas
  • Arquivos enviados pelo próprio cliente
  • Materiais gerados mês a mês
  • Histórico completo de entregáveis

⚡ Quando usar qual

  • Abrir projeto no Claude.ai → contexto carregado automaticamente
  • Pedir produção no Cowork → arquivo salvo direto na pasta
  • Novo briefing chega → Claude processa e organiza no computador
  • Você decide o que sobe pro projeto Claude.ai

🔄 Manutenção mensal

  • Atualizar histórico de resultados no projeto Claude.ai
  • Salvar relatório do mês na pasta do cliente
  • Novos materiais do cliente em 05_Materiais
  • Revisar objetivos se houve mudança de plano
